# SEC 標準 US-GAAP 普通股淨利 TTM P/E 候選公式驗證

> 檢查日期：2026-11-15（香港時間）；DEV 估值基準：2026-11-13；Git branch：dev。
> **唯讀研究**。本報告沒有更改正式 P/E 定義、五種估值倍數、資料庫或排程。

## 結論

- **不建議直接取代目前 Price / TTM Diluted EPS 的 P/E**。市場市值 / TTM basic common-stockholder income 不是同一指標：分子包含不同股數時點，分母可能反映優先股、基本與稀釋口徑，以及申報期間的股數變化。
- 缺少 EPS 的 **1,247** 格中，有 **331** 格能以同一財年原始 SEC 標準 NetIncomeLossAvailableToCommonStockholdersBasic 的 FY + Current YTD − Prior YTD 精確組成淨利；**171** 格淨利非正。**160** 格淨利為正，其中 **72** 格另有來源一致的單一上市類別、當日價格與 Futu 市值快照，可計算「候選」倍數。
- 72 格中僅 **44** 格能進一步使用近 90 日內已公開的 SEC 普通股股數，於 2% 內交叉核對 Futu 市值所隱含的股數。**26** 格缺近期 SEC 股數，**1** 格相差 2–5%，**1** 格（SUNS）偏離約 62.6%。因此 **72 非保證可正式恢復的數量，44 也不是無前視偏差的證明**。
- 原有有效 P/E **1,496** 格中，**279** 格符合候選公式與價格／市值初步門檻，當中 **59** 格相對差異超過 5%、**20** 格超過 10%，最大絕對相對差異 **50.84%**。即使是額外通過 SEC 股數 2% 交叉核對的 **179** 格，仍有 **40** 格差異超過 5%、**10** 格差異超過 10%。

## 資料與計算方法

1. 基準：DEV PostgreSQL stock_valuation_daily 與 stock；只讀 2026-11-13 的 P/E 欄位、原因碼、實際收入報期與股價。基準為 1,247 缺值與 1,496 已有效。
2. SEC：sec_financial_fact 僅 taxonomy=us-gaap、unit=USD、NetIncomeLossAvailableToCommonStockholdersBasic，篩選 10-K、10-Q 及正式 /A；available_from_date 不得晚於估值日，observed_at 不得晚於被比較估值的 calculated_at。每個期間採估值日已可用的最新 filed 版本，最新日若有不同值則不採用。
3. 實際財政年：FY 必須為公司真實的 364–371 日申報年度；Current YTD 起點必須緊接 FY 期末；Prior YTD 與 FY 起點一致，長度與 Current YTD 差異最多 8 日且 FY 剩餘季度長度須為 80–100 日。**Current YTD 與對比 Prior YTD 必須在相同 SEC accession 出現同值**，FY 不得晚於 Current YTD 版本申報。並非假設所有公司都是 12/31 年結。當最新報期本身是完整年報，直接採其年度 common NI（原有有效 P/E 對照組有 15 格，缺值組為 0）。
4. 相同財政期的算式：**TTM Common NI = FY Common NI + Current YTD Common NI − Prior YTD Common NI**。不以 NetIncomeLoss 或 ProfitLoss 直接代替普通股股東淨利；也不推導 Q4 diluted EPS。
5. 候選市值：僅 USD、單一 ACTIVE 上市普通股類、名稱非明示 Class X、CIK 一致、FUTU_CLOSE_SNAPSHOT、快照股價與已存收盤價八位精度相符、quote_time 等於 valuation_cutoff，且 observation 在 cutoff 後、calculated_at 前的股票。由 snapshot_market_cap 直接作價格總額分子。其他 OBSERVED_SHARES 與多股類推導不作自動替代。
6. 股數交叉核對：使用估值日前公開、最近 90 日內的 SEC CommonStockSharesOutstanding；比較 snapshot_market_cap/close_price 所隱含的股數與 SEC 股數。**2% 為研究篩查帶，不是會計或 PIT 證明，也不是程式的新容差規則**。
7. 以上依估值日已公開資料判斷標準；Futu 快照在 2026-11-15 才讀入而 quote_time 標為 2026-11-13，無法單憑此欄證明其股數在 11/13 收盤當時已可得。**不把候選等同真正可回測 PIT 市值**。

| 最新報期缺 Current YTD common NI | 159 |
| 無法連上前一財政年度 FY common NI | 101 |

| 上年同期 YTD 沒有同 accession 比較值 | 1 |

在 331 個完整 common NI 中，非正值 **171**，正值 **160**。後者只有 **72** 可通過上述 Futu 當日市值快照初步門檻；其他 **88** 格主要是僅有 issued-shares 市值推導（57）、快照時間不符合當日收盤（30）、沒有可驗證的市值來源（1）。

另行看全 1,247 格：符合「單上市股類＋當日同價快照」的有 **837**；257 格快照時間未符合，136 格只可由 issued-shares 估算，13 格標示為 Class、4 格無可證明的市值來源。**市值可用，不代表普通股淨利的三段期間也完整**。

## 差異來源的具體驗證

- **股數時點／稀釋：** 使用原始 SEC Company Facts 的 2026 九個月 Diluted Weighted-Average Shares 比對 Futu 收盤市值隱含股數，TSLA 的市值股數高約 11.7%，其候選 P/E 也高約 11.71%；BAC 的市值股數比加權稀釋股數低約 5.6%，候選 P/E 低約 5.57%；PYPL 分別約 -6.4%／-7.92%。這是時點股數與稀釋加權股數不同的有力證據，但不能當作普遍精確換算公式。
- **超出單純股數差額的差異：** AGEN 市值股數比 2026 九個月稀釋加權股數低約 11.7%，但候選 P/E 卻高 47.65%；PGEN 分別約 -13.7% 與 +46.92%。股數差異不足解釋倍數差異，仍需逐案核對 Futu 單季 EPS、SEC basic common NI 與非經常性損益／版本；不能推定新公式或舊公式更正確。
- **優先股／common income：** SEC 2026 九個月 PreferredStockDividendsIncomeStatementImpact：GS 約 6.28 億美元、ATLC 約 693.9 萬美元、AGEN 約 16.3 萬美元。官方 common NI 標籤已反映普通股權益相關調整，不可把合併 NetIncomeLoss 直接代用；basic 與 diluted 盈利分子亦可能不同。
- **非 12 月財政年度：** DIN 的前一財年實際截至 2025-12-28，Current YTD 從 2025-12-29 起；TXRH 的前一財年則截至 2025-12-30。依原始起訖日期匹配，未假設 1/1–12/31。
- **多股類與 ADR：** 有明示 Class X、同 CIK 多個上市股類、非普通股或幣別不一致的股票，並未被列為可直接用單一 ticker snapshot 當公司市值；這類必須按完整 issuer 資本結構重建。單一上市股類也不排除未上市股類，因此 72 格只作候選。
- **市值警訊：** SUNS 的快照市值／收盤價所隱含股數，約為原始 SEC 2026-09-30 普通股股數的 1.626 倍。這是明確的 scope 不確定性，不可憑較大的市值直接產生有效 P/E。
- **當前標籤未覆蓋：** AAPL、AA、MSFT、AMZN 等不能在本次嚴格候選中以 NetIncomeLossAvailableToCommonStockholdersBasic 完成全部期段。它們已有合併 NetIncomeLoss 並不等於可自動證明沒有非控股／優先股調整。

**決策：維持現有 P/E = Price / TTM Diluted EPS。** 不以新公式覆蓋原有 P/E；不因 common NI 和快照市值齊全就宣稱完全恢復 72 格。除兩公式經證實等價且所有 issuer 股類／股份時間基準一致，否則新比率應清楚標示為另一個非同口徑候選指標，不得偷換。
